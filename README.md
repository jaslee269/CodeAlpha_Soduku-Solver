# CodeAlpha Sudoku Solver

## Project Description
A Sudoku Solver developed using C++ that solves Sudoku puzzles using the Backtracking Algorithm.

## Features
- Takes Sudoku input from the user.
- Uses a 9×9 two-dimensional array.
- Checks row constraints.
- Checks column constraints.
- Checks 3×3 subgrid constraints.
- Solves Sudoku using recursion and backtracking.
- Displays the solved Sudoku puzzle.

## Technologies Used
- C++
- 2D Arrays
- Functions
- Recursion
- Backtracking

## How to Run
1. Download Sudoku.cpp.
2. Open it in a C++ compiler.
3. Compile and run the program.
4. Enter a 9×9 Sudoku grid.
5. Use 0 for empty cells.
6. View the solved Sudoku.
